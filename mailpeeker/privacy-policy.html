Privacy Policy

Mail Peeker — Stream Deck Plugin · Last updated: February 12, 2026

What Mail Peeker Does

Mail Peeker is a Stream Deck plugin that connects to your email accounts via IMAP to display recent email subjects and sender information on your Stream Deck keys. It supports password-based and OAuth2 authentication (Google, Microsoft).

Data We Collect

Mail Peeker does not collect, transmit, or store any personal data on external servers. All data stays on your local machine.

Specifically:

  • Email content: Email metadata (subject, sender, date) is fetched via IMAP and stored only in local memory and local cache files on your computer. Email bodies are never accessed.
  • Authentication credentials: Passwords and OAuth tokens are stored locally in the Stream Deck application's settings storage on your machine. They are never transmitted to any server other than the email provider's IMAP and OAuth servers.
  • OAuth tokens: When using Google or Microsoft sign-in, tokens are obtained directly from the provider and stored locally. The plugin acts as a confidential OAuth client — tokens are exchanged via a localhost callback server on your machine.
  • No analytics or tracking in the plugin: The Mail Peeker plugin itself does not include any analytics, telemetry, crash reporting, or tracking of any kind.
  • No external servers: Mail Peeker does not operate any backend servers. All communication is directly between your computer and your email provider.

Third-Party Services

Mail Peeker communicates directly with the following services, only when you configure an account:

  • Google: OAuth2 authentication (accounts.google.com), user profile (googleapis.com), and IMAP (imap.gmail.com)
  • Microsoft: OAuth2 authentication (login.microsoftonline.com), user profile (graph.microsoft.com), and IMAP (outlook.office365.com)
  • Other IMAP providers: Any IMAP server you configure (e.g., your company's mail server)

These services have their own privacy policies. Mail Peeker only requests the minimum permissions needed to read email metadata via IMAP.

Google API Scopes

Mail Peeker requests the following Google API scopes:

  • https://mail.google.com/ — Required for IMAP access (Google mandates this scope for all IMAP clients using OAuth; there is no read-only IMAP scope)
  • openid email profile — To identify your account (email address and display name)

Despite the broad scope name, Mail Peeker only reads email metadata (subject, sender, date) via IMAP. It does not read email bodies, send emails, delete emails, or modify your mailbox in any way.

Data Storage

  • All data is stored locally on your computer within the Stream Deck application's data directory
  • Email cache files are stored in the plugin's local data folder
  • You can delete all stored data by removing the plugin from Stream Deck

Data Sharing

Mail Peeker does not share any data with anyone. There are no third-party analytics, advertising, or data processing services.

Your Rights

Since all data is stored locally on your machine, you have full control over it. You can:

  • Remove any email account from the plugin settings at any time
  • Revoke OAuth access via your Google or Microsoft account settings
  • Uninstall the plugin to remove all locally stored data

Website Analytics

This website (tiptronic.github.io) uses GoatCounter for basic traffic analytics. GoatCounter is privacy-friendly and:

  • Does not use cookies
  • Does not collect personal data
  • Does not track users across sites
  • Only counts page views, referrers, and basic browser/country information
  • Is fully GDPR compliant without a consent banner

This analytics applies only to the website, not to the Mail Peeker plugin itself. The plugin contains no analytics of any kind.
